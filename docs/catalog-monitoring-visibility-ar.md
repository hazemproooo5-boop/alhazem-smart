# فصل سجلات الكتالوج قيد التحقق عن المنتجات الموثقة

- تمت إضافة قائمة منفصلة باسم catalogMonitoringProducts للسجلات المستوردة التي لم تجتز بوابة التوثيق.
- لم يتم تخفيف شروط isCatalogReady؛ المنتج لا يظهر كمنتج موثق إلا إذا اجتاز شروط الصورة والمصدر والموديل والمواصفات وتاريخ التحقق والتوفر.
- مركز الكتالوج يعرض الآن قسمين مستقلين: المنتجات الموثقة، والسجلات قيد التحقق.
- جدول المراجعة يعرض الاسم والموديل والعلامة وحالة التحقق ورابط المصدر إن توفر.
- لا يعرض الجدول أسعاراً أو أزرار شراء أو مقارنة، ولا يربط السجلات غير الموثقة بصفحات تفاصيل المنتج.
- أضيف تنبيه واضح بأن السجلات ليست عروض شراء معتمدة وأن الصور والمواصفات والتوفر والضمان المحلي ما زالت بحاجة إلى مراجعة.
- لا توجد أي تغييرات على الأسعار أو المواصفات أو حالة التحقق أو التوفر.
