# مصفوفة تتبع متطلبات الحازم سمارت
## المرجع: وثيقة إنشاء الحازم سمارت — المخطط التنفيذي — الإصدار 1.0

**الحالة:** سجل تأسيسي للمراجعة والتنفيذ، وليس شهادة اكتمال.  
**تاريخ إعداد السجل:** 2026-11-15  
**المستودع:** hazemproooo5-boop/alhazem-smart  
**قاعدة التقييم:** لا تُعد الصفحة المنفذة دليلاً على اكتمال الوظيفة. لا تُعتمد معلومة منتج أو سعر أو ضمان دون مصدر وحالة تحقق واضحة.

### تعريف الحالات
- **جزئي:** يوجد عرض أو نموذج أولي، لكن الوظيفة أو البيانات أو التكامل غير مكتمل.
- **غير منفذ:** لم يظهر تنفيذ وظيفي في مراجعة الملفات المتاحة.
- **يحتاج تكامل/بيانات:** يتطلب خدمة خلفية أو مزوداً أو بيانات تشغيلية موثوقة.
- **يتطلب اختباراً:** لا يمكن إثباته من قراءة الشيفرة وحدها.

## أولويات التنفيذ التالية

1. **P0 — ضبط البيانات والثقة:** توحيد نموذج المنتج/الماركة/المورد/السعر/المصدر/التوفر/الضمان وتواريخ التحقق وحالات التوثيق، ومنع عرض الأسعار القديمة كأنها حالية.
2. **P0 — اختبار الوظائف الحالية:** اختبارات فعلية للمسارات الرئيسية، تفاصيل المنتج، البحث، المقارنة، المستشار، الروابط، الصور، RTL، والجوال.
3. **P1 — مواصفات البيانات والإدارة:** Product Data Dictionary وBrand/Supplier schema وPermissions Matrix وAudit Log design.
4. **P1 — استكمال تجربة القرار:** احتياج موسع، تفسير التوصية، مقارنة متعددة المعايير، بدائل، وطلب استشارة.
5. **P2 — الخدمات الخلفية:** PostgreSQL وAPI ومصادقة وصلاحيات وتخزين وسجل تدقيق ونسخ احتياطية.
6. **P2 — البحث وRAG:** فهرسة موثقة، بحث هجين، استرجاع المصادر، تقييم الجودة، ومنع الإجابات غير المسندة.
7. **P3 — الثقة وما بعد الشراء:** نظام «انصح غيرك» وجدولة المتابعة والمراجعة البشرية وحق الرد.
8. **P4 — التجربة الافتراضية والتوسع:** المطبخ الذكي وAR/VR وتطبيق الهاتف والتكاملات.

## قواعد تحديث هذا السجل

- لا تتحول الحالة إلى «مكتمل» إلا برابط تنفيذ واختبار قبول ناجح على SHA محدد.
- كل معلومة تجارية تعرض للمستخدم يجب أن تحمل مصدراً وتاريخ تحقق وحالة توثيق؛ وإلا تعرض بوضوح بأنها تحتاج تأكيداً أو تُحجب.
- لا تُنشأ شركات أو موديلات أو صور أو أسعار افتراضية لإكمال العدد أو شكل الصفحة.
- لا تُحذف ميزة أو بيانات قائمة دون قرار صريح ومراجعة أثر.
- هذا السجل مشتق من متطلبات وثيقة الإصدار 1.0، ويضاف إليه دليل التنفيذ والاختبارات دون تغيير مرجعية الوثيقة.
