# تقرير تدقيق قابل للتنفيذ — تحديث 18 نوفمبر 2026

تم توسيع تقرير audit:catalog ليحتوي على قوائم معرفات الموديلات التي ينقصها:
- الموديل المحدد.
- مصدر المنتج.
- صورة مطابقة.
- حالة توفر واضحة.
- مواصفات.

كما تم تعديل معيار missingAvailability حتى لا يصنف عبارة "غير متوفر" وحدها كحقل ناقص؛ فحالة النفاد الموثقة تختلف عن حالة التوفر غير المعروف.

تم تحديث GitHub Actions لرفع catalog-audit-summary.json وcatalog-audit.csv كأثر بناء لمدة 30 يوماً بعد نجاح التدقيق وفحص TypeScript وبناء Vite. بذلك يمكن مراجعة جميع الموديلات الناقصة بدلاً من الاعتماد على الأعداد الإجمالية فقط.

لا تغييرات على بيانات المنتجات أو الأسعار أو الصور في هذا التحديث.
