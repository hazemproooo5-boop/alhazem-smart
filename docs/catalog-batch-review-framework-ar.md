# إطار المراجعة الجماعية لكتالوج الحازم سمارت

## الهدف
مراجعة جميع الماركات والفئات والموديلات على دفعات متوازية، بدلاً من توثيق موديل واحد في كل مرة. إضافة رابط أو اسم موديل ليست تحققاً تجارياً مكتملاً.

## الجرد الحالي
يُستخرج الجرد آلياً من ملفات البيانات الحالية عند تشغيل \`npm run audit:catalog\`. يشمل المنتجات وموديلاتها وماركاتها وفئاتها، وحالة التوثيق، والمصدر والصورة والتوفر، وقائمة الماركات. ينتج تقرير CSV تفصيلي وملخص JSON داخل \`reports/\`.

## ترتيب الدفعات
1. جميع المنتجات ذات الموديل المحدد ورابط المصدر، عبر كل الماركات والفئات.
2. المنتجات ذات الموديل المحدد التي ينقصها المصدر أو الصورة.
3. الماركات المسجلة بلا منتجات: تحديد الموقع الرسمي والكتالوج والفئات.
4. الأجهزة غير المنزلية والتكييف التجاري والمركزي ثم بقية الفئات.
5. إعادة فحص السعر والتوفر كل 48 ساعة وفق الجدولة المعتمدة.

## بطاقة التحقق لكل موديل
- العلامة والموديل والنسخة والسوق المصري.
- رابط صفحة المنتج الرسمية أو البائع المباشر.
- المواصفات المنقولة من المصدر فقط.
- صورة مطابقة للموديل والنسخة.
- السعر والعملة وتاريخ الرصد ورابط السعر، والضرائب والشحن إذا ظهرا.
- حالة المخزون من المصدر نفسه؛ وجود صفحة المنتج لا يثبت التوفر.
- الضمان المحلي والوكيل لا يعتمدان إلا بمصدر محلي موثوق.
- نتيجة كل حقل: موثق / غير متاح / متعارض / يحتاج تأكيد.

## آلية الدفعات السريعة
- 20–30 موديل في دفعة تدقيق واحدة، مع توزيعها على الماركات والفئات وعدم تركيز الدفعة في ماركة واحدة.
- تجميع صفحات الشركة الرسمية والكتالوجات المشتركة لتقليل تكرار البحث، ثم مطابقة كل موديل على حدة.
- عند تعذر إثبات الموديل أو النسخة، يسجل سبب التعذر بدلاً من التخمين.
- لا يرفع المنتج إلى Verified إلا بعد اكتمال المصدر والمواصفات والصورة والتاريخ والتوفر ومتطلبات بوابة الكتالوج.
- السعر غير الموثق لا يعرض كسعر حالي؛ وإذا عرض وفق السياسة فيوسم «السعر التقريبي» مع المصدر والتاريخ.

## التشغيل
\`\`\`bash
npm run audit:catalog
\`\`\`

ينتج:
- \`reports/catalog-audit-summary.json\`
- \`reports/catalog-audit.csv\`

هذا فحص آلي لجودة الجرد ونواقص البيانات، ولا يدعي التحقق من السعر الحي أو التوفر. التحقق التجاري يتطلب فتح المصدر الأصلي لكل موديل وتسجيل وقت الرصد.

## تعريف الإنجاز
تقاس التغطية بعدد الموديلات التي اجتازت التحقق فعلاً، لا بعدد الأسماء أو الروابط المضافة. ويظهر في كل تقرير إجمالي الموديلات والموثق وغير الموثق والناقص والمتعارض وما فُحص في الدفعة الحالية.
